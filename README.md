# anselman.com

A lava lamp with three links on it: [Write On](https://write-on.app),
[Rant Recorder](https://rantrecorder.com), and the GitHub account that holds
everything else. Static page, Vite build, published to the `deploy` branch by
CI on every push to `main`.

Press F for fullscreen. Click the lamp to change its colour.

The earlier version was a recruiter portfolio with a resume, an employment
history and a notes feed. It is archived, still runnable, in
`archive/spa-portfolio-2026-09/` with the reason it was retired.
