# anselman.com

My site — [anselman.com](https://anselman.com). Routed SPA over a
lava-lamp video backdrop, with a notes feed (Supabase) and the resume.

![anselman.com](docs/readme/site.jpg)

Small build, opinionated details: the backdrop is self-hosted video
with a watchdog (a YouTube iframe died once on a recruiter, never
again), the favicon is a settled blob from the lamp itself, and the
production-blank-page incident taught the `.htaccess` SPA-rewrite +
credential-fallback lesson the hard way.

Deployed via git; if you're reading this on GitHub, the site probably
brought you here — the repos are the real portfolio.
